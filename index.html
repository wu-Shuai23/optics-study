学习路径总览Learning path & dependency map

光电子技术的知识不是并列的，而是一条信息链：把电信号变成光（光源）→ 让光在介质里走（波导/光纤）→ 把信号"写"到光上（调制）→ 在接收端把光变回电（探测）→ 用一堆器件把这条链组装成系统（显示、存储、通信）。下面的路径图同时给出阶段顺序和模块间的依赖，按箭头方向学，任何一环卡住都能知道缺的是哪块前置知识。

0.1　三句话把握整门课的逻辑

① 一切靠"能带/能级"对话

光子能量 E = hν = 1.24/λ(μm) eV 是与材料带隙 Eg 对话的"汇率"。发光要求 hν ≈ Eg（或略小），探测要求 hν ≥ Eg。这一条能推出全部光源与探测器的波长窗口。

② 一切指标都是"效率×带宽"的取舍

内量子效率决定亮度，RC 与渡越时间决定速度；增益越高（APD）噪声越大；耦合越强（谐振腔）谱线越窄。答题时先想"这个参数被谁限制"。

③ 一切系统都是功率预算与色散预算

发射功率 → 光纤损耗 → 分路/接头 → 需高于接收灵敏度（含余量）。速率越高，色散与噪声越致命。系统题几乎都是这两个预算的算术。

1.1　定义与边界

光电子技术是研究光（光子）与物质（主要是电子）相互作用，并以此实现光信号的产生、传输、调制、探测、处理与显示的技术学科。它由"光学"与"电子学"交叉而成，但落点始终是器件：把物理效应做成可用的、有指标的功能件。

  • 信息光电子：关心带宽、噪声、误码、串扰。含光通信、光互连、光存储、光显示、光传感、光计算。信号是"弱"的，追求保真。
  • 能量光电子：关心功率、效率、光束质量。含激光加工/切割/焊接、激光医疗、激光武器、激光核聚变、光伏发电。信号是"强"的，追求能量密度。

1.2　光电子系统的最小构成

任何光电子系统都能拆成 电光转换（E/O）→ 光信道 → 光电转换（O/E）三段，中间插入光放大与监控。答题时的万能骨架：光源产生光 → 调制器把信息写到光上 → 光纤传输（损耗+色散）→ 探测器把光变回电 → 放大判决。把这条线的每一环的"限制因素"写出来，就是半张卷子。

2.1　从麦克斯韦方程到光波（推导主线）

这一节的考点不是背方程，而是会走这条链：

∇×E = −∂B/∂t，  ∇×H = J + ∂D/∂t，  ∇·D = ρ，  ∇·B = 0
无源、线性、各向同性介质（ρ=0, J=0）→ 两边取旋度并代入 → 得波动方程
∇²E − μ0μrε0εr ∂²E/∂t² = 0   ⟹   v = 1/√(μ0μrε0εr) = c/n
n = √(εrμr) ≈ √εr（非磁性介质 μr≈1）。这就是"折射率来自介质的极化响应"的严格出处。

时谐解取 E(r,t) = E0 exp[i(k·r − ωt)]，其中 k = 2π/λ = nω/c。E、H、k 三者两两垂直且成右手系，且同相位——这是光波"横波性"的根源，也是偏振、双折射、全反射相位突变等一系列结论的出发点。

2.2　光波的四个基本量

频率（颜色身份）

ν = c/λ跨越介质时 ν 不变，λ 变。所以"颜色"由频率（光子能量）决定。通信中常用光频 193.1 THz（1550 nm）。

光子能量（与材料对话）

E = hν = 1.24/λ(μm) eV记住 1.24 这个常数，发光/探测/带隙三章全靠它。

光强（可测量）

I = ½ n ε0 c E0²∝ E0²。探测器、非线性效应、光强分布都从这里出发。

波长/波矢（几何相位）

k = 2πn/λ0决定干涉、衍射、光栅方程与相位匹配条件。

2.3　偏振：光波的矢量性

偏振描述的是 E 矢量端点的轨迹。三个自由参数决定一个偏振态：两正交分量的振幅比与相位差 δ。任意偏振态都可用 琼斯矢量 表示：

线偏振 (θ)：[cosθ, sinθ]T    圆偏振：1/√2 · [1, ±i]T    椭圆：一般 [Ex, Eyeiδ]T
δ = 0 或 π → 线偏振；δ = ±π/2 且 Ex=Ey → 圆偏振（正/负对应右旋/左旋）；其余 → 椭圆偏振。

2.4　相干性：能不能"干涉"

干涉三条件：频率相同、振动方向有平行分量、相位差恒定。工程上用两个长度刻画"相干性有多好"：

Lc = c/Δν = λ²/Δλ   (时间相干长度)     τc = Lc/c   (相干时间)
含义：光程差超过 Lc 就看不到干涉条纹。LED（Δλ≈30 nm，λ=850 nm）→ Lc≈24 μm；DFB 激光器（Δλ≈0.1 nm）→ Lc≈1.7 cm。所以干涉型传感器必须用窄线宽光源，而 OCT（光学相干层析）反过来利用"短相干长度"实现深度选通。

空间相干性由光源的发光面积决定：相干面积 Ac ~ λ²/Ω（Ω 为光源对观察点的立体角）。太阳光几乎无空间相干性，激光则是"空间相干性极好"的典型。

2.5　高斯光束：激光的真实形状

平面波是理想模型。真实激光器输出的是基模高斯光束：横截面光强为高斯分布，束宽沿传播方向按双曲线变化，在束腰处最细。

w(z) = w0√(1 + (z/zR)²)，  zR = πw0²n/λ，  θdiv = λ/(πn w0)
zR 为瑞利长度（光束面积近似不变的"准直区"长度）。关键结论：w0·θ = λ/(πn) 为不变量——想把光斑聚焦得越小，发散角必然越大。这就是"衍射极限"的定量表述，也是激光加工中"焦深与光斑"取舍的根源。

2.6　介质界面：反射、折射、全反射

三个必须会用的结论：

n1sinθ1 = n2sinθ2  |   tanθB = n2/n1  |   sinθc = n2/n1（仅 n1>n2）
布儒斯特角：反射光与折射光互相垂直，反射光为纯 s 偏振（p 分量反射率为零）→ 激光器的"布儒斯特窗"靠它实现无反射损耗的线偏振输出。临界角：超过即发生全反射，反射率 100%，这是光纤与集成光波导的物理基础（模块 04）。

2.7　色散：为什么"不同颜色跑得不一样快"

vp = c/n(λ)    vg = c/ng，  ng = n − λ·dn/dλ
相速度是等相位面的速度，群速度是能量（脉冲包络）的速度，也是信息速度。正常色散 dn/dλ<0（可见光区多数材料），反常色散 dn/dλ>0（吸收带附近）。超短脉冲、光孤子、光纤色散补偿都建立在 vg 上。
易错点
  • 光从空气进入玻璃：频率不变、波长变短、速度变慢。常有人答"波长不变"。
  • 全反射时"没有光进入第二种介质"——错，存在消逝波（场强按指数衰减），否则光纤耦合、受抑全反射都无法解释。
  • 布儒斯特角与临界角不是同一个角：前者 tan 关系、用于消反射；后者 sin 关系、用于全反射。数值也常不同。
  • 群速度可以小于 c/n 甚至小于 c，但在正常色散区不会超过 c；"相速度超光速"不违反相对论。
一句话记忆 一个常数 1.24（eV·μm），两个速度（相速 c/n、群速 c/ng），三个角（布儒斯特 tan、临界 sin、发散 λ/πw0），一条双曲线（高斯包络）。

3.2　三种跃迁与爱因斯坦系数

两能级系统（E2>E1，hν = E2−E1）中只有三种基本过程。这是整章的地基：

dn2/dt = B12ρνn1 − B21ρνn2 − A21n2
热平衡下 dn2/dt = 0 且 n2/n1 = (g2/g1)exp(−hν/kT)，与普朗克公式对照可得两条只依赖材料、与温度无关的关系：
① g1B12 = g2B21（吸收与受激辐射的"能力"对称，仅差简并度）；
② A21/B21 = 8πhν³/c³（自发辐射占比随 ν³ 增长 → 高频器件（蓝光/紫外）天生难做激光器，这就是 GaN 蓝光激光器比红光晚 30 年的根本原因）。

3.3　粒子数反转：激光的"入场券"

光通过介质时净效果是吸收还是放大，取决于受激辐射与吸收谁占上风：

净增益 ∝ (N2/g2 − N1/g1) > 0  ⟺  粒子数反转  ⟺  T等效 < 0
热平衡时 N2 < N1 恒成立，所以热平衡下不可能有激光，必须靠外部泵浦把粒子"顶"上去，形成"负温度"的非平衡态。

3.4　增益、阈值与纵模

I(z) = I0e(g−α)z   gth = α + (1/2L)·ln[1/(R1R2)]
g 为增益系数，α 为腔内总损耗（含散射、吸收、耦合）。阈值条件来自"往返净增益 = 1"：光走一圈回来强度不减小才能起振。R1、R2 是两腔镜反射率，若一端输出，则该项≈输出损耗。
相位条件：2kL = 2πq ⟹ νq = q·c/(2nL) ⟹ Δν = c/(2nL)
纵模间隔只由光学腔长 nL 决定。L=1 mm 的半导体腔：Δν ≈ 90 GHz（0.7 nm @1550nm）；L=30 cm 的 He-Ne：Δν ≈ 500 MHz。增益谱宽 > 纵模间隔 → 多模振荡；要单模就把腔做长（间隔变小）+ 加滤波器，或用 DFB 结构。

4.1　导光的本质：全反射 + 相位匹配

光纤不是"空心的管子把光关住"，而是靠全反射把光限制在高折射率芯层。几何光学给出"能不能导"，物理光学给出"能导几个模"——两套语言都要会。

sinθc = n2/n1   NA = n0sinθmax = √(n1² − n2²) ≈ n1√(2Δ)   Δ = (n1−n2)/n1
NA（数值孔径）是光纤的"进光锥角"：只有入射角小于 θmax 的光才能被导引。典型值：多模 50/125 光纤 NA≈0.20，单模 9/125 光纤 NA≈0.12（对应 θmax≈7°）。NA 越大收光越多但模式越多、色散越大——这是多模与单模的根本取舍。

4.2　光纤的结构与折射率分布

标准通信光纤是三层同心结构：纤芯（9 μm 单模 / 50 或 62.5 μm 多模）+ 包层（125 μm）+ 涂覆层（250 μm）。包层直径固定 125 μm 是全球统一的机械基准，纤芯尺寸才决定光学性质。

4.3　V 参数与模式判据（最常考的公式）

V = (2πa/λ)·NA = (2πa n1/λ)√(2Δ)  ⟹  V < 2.405 时为单模
V 是"归一化频率"，一个数同时包含波长、纤芯半径与折射率差。V < 2.405 只允许 HE11（LP01）一个模。模式数：阶跃型 M ≈ V²/2，渐变型 M ≈ V²/4。反过来，单模工作有截止波长 λc：λ > λc 时才单模，所以"同一根光纤在 1310 nm 单模、在 850 nm 多模"是正常现象。

典型 G.652 单模光纤：a=4.1 μm，Δ=0.36%，n₁=1.452 → V≈2.4 在 1310 nm，λc≈1260 nm。这也是为什么早期系统先用 1310 nm 窗口。

4.4　损耗：为什么"两个窗口"分别管损耗和色散

α(dB/km) = −(10/L)·lg(Pout/Pin)  ⟺  Pout = Pin·10−αL/10
注意是 10lg（功率比），不是 20lg（那是幅度比）。例：0.2 dB/km × 100 km = 20 dB = 功率衰减 100 倍。

4.5　色散：脉冲为什么会被"抹平"

D = D材料 + D波导 = −(λ/c)·d²n/dλ² + DW  [ps/(nm·km)]
三类色散：① 模间色散（多模光纤专属，不同模路径不同，最大）；② 材料色散（折射率随波长变，不同"颜色"速度不同）；③ 波导色散（模场在芯/包层的功率分配随波长变化）。三者中模间色散最致命，这就是长距离必用单模的原因。
Δτ = D·L·Δλ  ⟹  B·L ≤ 1/(D·Δλ)  （色散受限）
例：D=17 ps/(nm·km)，L=100 km，光源 Δλ=0.1 nm → Δτ≈170 ps，对应约 2.9 Gb/s 上限。所以高速长距系统必须用窄线宽光源 + 色散补偿光纤/模块。单位换算陷阱：1 ps/(nm·km) 的 D 在 1 nm 谱宽、1 km 上产生 1 ps 展宽。

5.2　电光效应：用电场改折射率

Δ(1/n²)ij = Σk rijkEk + Σkl sijklEkEl

T = Pout/Pin = cos²(Δφ/2) = cos²(πV/(2Vπ))

6.2　四条核心公式（必须能互相推导）

这是全章最核心的一组关系。量子效率 η = 每个入射光子产生的电子数；响应度 R = 每瓦光功率产生的电流。两者只差一个常数 hν/e。重要推论：R 正比于 λ——同一个探测器，在 1550 nm 的响应度是 850 nm 的 1.8 倍（只要 η 相同），因为"每个光子能量更小、同样功率下光子数更多"。

截止波长：光子能量小于带隙就无法本征吸收，探测器在长波方向陡然失效。它同时给"能探测"和"不吸收"画了线：Si 的 λc=1.1 μm，所以 1550 nm 光对硅是透明的（硅光要用 Ge 或 III-V 做探测）。

B ≈ 1/(2πRtotCj)  与  ttr = w/vsat 取较慢者

散粒噪声来自"电流是离散电子"的统计性，与电流成正比 → 信号越强噪声也越强，是"散粒噪声极限"；热噪声来自负载电阻的布朗运动，与电流无关 → 弱信号时热噪声主导。APD 的倍增会把信号放大 M 倍、噪声放大 M²F(M) 倍，所以 SNR 改善 ∝ M/√F(M)，存在最佳 M。
SNR = Ip²/(i²散粒 + i²热)   Pmin = NEP·√Δf
两种极限：热噪声极限下 SNR ∝ P²（平方关系，增功率改善慢）；散粒噪声极限下 SNR ∝ P（线性）。这就是相干探测加本振光能提升灵敏度的原因——把系统从热噪声极限推进到散粒噪声极限。
一条"设计三角形"（答题万能框架） 任何探测器的设计都在效率 η、带宽 B、噪声/灵敏度之间取舍，而它们由同一组结构参数控制：耗尽区厚度 w。w↑ → η↑（吸收更充分）、C↓（带宽↑）、但渡越时间↑（带宽↓）且偏压↑。所以真实器件总在 w 上做折中，这也是"为什么 PIN 的 i 层取 1–5 μm"的标准答案。
易错点
  • 响应度 R 的单位是 A/W，别与量子效率（无量纲）混用；R 随 λ 增大，η 却不随 λ 增大。
  • 截止波长算的是"能吸收"的长波极限；短波极限由表面复合、材料透明度决定，不是带隙。
  • APD 的增益 M 越大越好——错。SNR 在某个 Mopt 处最大，之后因 F(M) 迅速恶化。
  • 暗电流会贡献散粒噪声，不只影响直流偏置；制冷主要是压暗电流。
  • 光功率与光电流是平方/线性关系混用：I ∝ P（线性），而电功率 ∝ P²。
一句话记忆 一个截止波长（1.24/Eg）、一个响应度（ηλ/1.24）、一个三角形（w 决定 η-B-噪声）、两个噪声（2eIΔf 与 4kTΔf/R）。

8.2　光放大器：把"电再生"换成"光放大"

没有光放大器的时代，每隔 40–80 km 就要"光→电→判决→整形→电→光"再生一次，成本与速率都受限。EDFA 让"全光中继"成为可能，是 1990 年代光通信容量爆炸的直接推手。

G = Pout/Pin = exp[(Γg − α)L]   NF = 2nsp(G−1)/G + 1/G ≈ 2nsp ≥ 3 dB
噪声系数 NF 的 3 dB 是"量子极限"（来自自发辐射的最低噪声），实际 EDFA 为 4–6 dB。关键结论：增益越大，NF 越接近 2nsp（不再随 G 增长），所以第一级放大器要"高增益 + 低噪声"，第二级才追求"高饱和功率"。
Psat：输出功率饱和点  ⟹  多波道系统必须让总功率 < Psat，否则"强波道压制弱波道"
这是 WDM 系统中"增益平坦 + 功率均衡"问题的来源：EDFA 的增益谱在 1530–1565 nm 内并不完全平坦（有 ±0.5–1 dB 起伏），级联几十个放大器后，通道间功率差会被放大成"某些通道 BER 崩溃"。

自测题（12 题，含解析）Self-check with worked solutions

建议：先遮住答案独立算，再展开对照。能算对 9 题以上，说明这条学习路径已经走通。

1. 1550 nm 光子的能量（eV）与频率（THz）各是多少？
E = 1.24/1.55 = 0.80 eV；ν = c/λ = 3×10⁸/1.55×10⁻⁶ = 1.935×10¹⁴ Hz = 193.5 THz。
记忆点：0.8 eV 恰好低于 Si 的 1.12 eV 带隙 → 硅对它透明，所以必须用 InGaAs 探测。
2. 某阶跃光纤 n₁=1.452，n₂=1.447，纤芯半径 4.1 μm。求 NA；判断 1310 nm 时是否单模。
NA = √(1.452²−1.447²) = √0.014495 ≈ 0.120；θmax = arcsin(0.12) ≈ 6.9°。
V = 2πa·NA/λ = 2π×4.1/1.31 × 0.120 ≈ 19.66×0.120 ≈ 2.37 < 2.405 → 单模。
注意：a 用半径；若误用直径 8.2 μm，V 会算成 4.7，判成多模。
3. 一条 100 km 链路，光纤 0.22 dB/km，两端连接器各 0.5 dB，中间 4 个熔接点各 0.1 dB。总损耗？
22 + 1.0 + 0.4 = 23.4 dB。若发射 0 dBm，则到达 −23.4 dBm。
工程上还要再加 3–6 dB 余量（老化、弯曲、温度），实际按 27–29 dB 设计。
4. 半导体激光器腔长 L=300 μm，α=10 cm⁻¹，两端镜面反射率 R₁=R₂=0.3。求阈值增益。
gth = α + (1/2L)ln[1/(R₁R₂)]，L=0.03 cm。
ln(1/0.09)=ln11.11=2.408；2.408/(2×0.03)=40.1 cm⁻¹；gth = 10+40.1 = 50.1 cm⁻¹。
解读：镜面损耗（40）远大于内部损耗（10）→ 所以实际器件会镀高反膜/增透膜来调配 R。
5. InGaAs PIN，η=0.80，λ=1.3 μm。求响应度；若接收光功率为 −20 dBm，光电流多大？
R = ηλ/1.24 = 0.8×1.3/1.24 = 0.839 A/W。
−20 dBm = 10 μW → I = 0.839×10×10⁻⁶ = 8.39 μA。
再进一步：若负载 50 Ω，热噪声 in=√(4kTΔf/R)，取 Δf=1 GHz，in≈0.57 μA → SNR ≈ 20lg(8.39/0.57) ≈ 23 dB。
6. 为什么 Si 探测器在 1550 nm 完全无响应，而同一块 Si 可以做 850 nm 的高速探测？
Si 的 Eg=1.12 eV → λc=1.24/1.12=1.11 μm。1550 nm 光子只有 0.8 eV，不足以跨越带隙，无法本征吸收，所以透明。
850 nm（1.46 eV）远高于带隙，吸收系数约 10³–10⁴ cm⁻¹，几微米即可吸收完 → 可以做高速 PIN。
7. MZI 调制器 Vπ=5 V，偏置在 Vπ/2。小信号幅度 0.5 V 时，输出光强相对变化约多少？
T=cos²(πV/2Vπ)。在 V=Vπ/2 处 dT/dV = −(π/2Vπ)sin(πV/Vπ) = −(π/10)·1 ≈ −0.314 /V。
ΔT ≈ 0.314×0.5 ≈ 0.157，即光强变化约 ±16%（相对中点 0.5 则为 ±31%）。
要点：正交偏置点斜率最大，是线性调制的工作点。
8. 蓝光 LED 波长 450 nm，荧光粉发射峰值 560 nm。这样得到的白光，色域与显色性有什么先天限制？
光谱只有两个窄峰（蓝 + 黄），红光与青绿区缺失。
后果：① 显色指数 Ra 偏低（红色物体发暗/偏色）；② CIE 图上三角形只能覆盖"蓝-黄"连线附近，色域三角形又小又偏。
改进：加红光荧光粉（RGB 三色粉）或用量子点做窄谱转换，或直接用 RGB 三芯片/Micro-LED。
9. Blu-ray 的 λ=405 nm、NA=0.85。求焦斑直径，并与 CD（780 nm, 0.45）比较面密度。
BD：d=0.61×0.405/0.85 ≈ 0.291 μm；CD：d=0.61×0.78/0.45 ≈ 1.057 μm。
面密度比 =(NA₂/λ₂)²/(NA₁/λ₁)² = (0.85/0.405)²/(0.45/0.78)² = 4.41/0.333 ≈ 13.2 倍。
实际容量比 25/0.65≈38 倍，多出来的部分来自更薄的覆盖层、更强的纠错码与调制编码。
10. 一根光纤上有 λB=1550 nm 的 FBG，受到 1000 με 的拉伸应变。波长漂移多少？温度同时升高 10 K 呢？
应变灵敏度约 1.2 pm/με → Δλ ≈ 1.2 nm（红移）。
温度约 10 pm/K → 10 K 引起 ≈ 0.1 nm。
结论：应变与温度交叉敏感，工程上必须做温度补偿（双光栅、参考光栅或双波长解调）。
11. 脉冲 LiDAR 测得回波延迟 1.2 μs，目标距离多少？若脉宽 2 ns，距离分辨率多少？
d = cΔt/2 = 3×10⁸×1.2×10⁻⁶/2 = 180 m。
分辨率 ≈ cτ/2 = 3×10⁸×2×10⁻⁹/2 = 0.3 m。
要点：分辨率由脉宽决定，不是由采样率；要提高分辨率就要更短的脉冲（并配合更高的探测器带宽）。
12. 某太阳能电池 Voc=0.70 V，Jsc=40 mA/cm²，FF=0.80，入射 100 mW/cm²。求效率。
η = Voc·Jsc·FF/Pin = 0.70×0.040×0.80/0.100 = 22.4%。
三个因子各自的意义：Voc 受带隙与复合限制，Jsc 受吸收与收集效率限制，FF 受串联电阻与并联电阻限制。单结理论极限 33.7%（Shockley–Queisser）。
